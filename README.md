# Fleet & Route Performance Analytics

## Project Overview
Power BI solution developed for operational fleet and route performance monitoring.

The dashboard analyzes activity time, scheduled vs. out-of-schedule activity,
route compliance, stops, mileage and geographic deviations.

## Business Objectives
- Monitor fleet activity
- Identify operational deviations
- Analyze activity inside/outside assigned areas
- Monitor mileage and working-time compliance
- Support operational decision-making

## Technologies
- Power BI
- Power Query
- DAX
- Data Modeling
- Azure Maps

## Dashboard Features
- Fleet performance KPIs
- Scheduled vs. out-of-schedule analysis
- Stop analysis
- Mileage analysis
- Geographic visualization
- Interactive filtering

## Data Privacy
This public portfolio version uses anonymized and synthetic data.

The dashboard structure, analytical logic, KPIs and reporting methodology are
based on a real operational solution designed and developed by me.

Vehicle identifiers, personnel, locations and GPS coordinates do not represent
the original operational data.
